# Submission checklist

- [ ] Replace sample seed records if your assigned brief requires different sample data.
- [ ] Configure your own PostgreSQL database in `.env`.
- [ ] Run `npm install`.
- [ ] Run `npm run db:migrate` and `npm run db:seed`.
- [ ] Run `npm test` and retain the actual test output.
- [ ] Start the API and verify the health endpoint.
- [ ] Test create, list, detail, update and delete with Postman or curl.
- [ ] Capture screenshots of successful and rejected requests.
- [ ] Add your own GitHub repository URL and deployed API URL to this document/README.
- [ ] Confirm `.env` and credentials are not committed.
- [ ] Submit the public repository and requested evidence links.

Do not claim deployment, passing integration tests or review approval until you have personally verified them.
